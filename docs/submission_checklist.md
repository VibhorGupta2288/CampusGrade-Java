# VITyarthi Submission Checklist

- [x] Public-repository-ready project structure
- [x] Root-level README.md
- [x] Root-level statement.md
- [x] At least three major functional modules
- [x] Four or more non-functional requirements documented in report
- [x] Modular Java source structure
- [x] Command-line execution
- [x] Validation and error handling
- [x] Manual test runner
- [x] Architecture diagram
- [x] Workflow diagram
- [x] Use case diagram
- [x] Sequence diagram
- [x] Class/component diagram
- [x] Data/storage model diagram
- [x] Project report PDF
- [x] Sample data and sample run output
- [x] Git-ready .gitignore

Before portal submission:

1. Create a GitHub repository with the final project folder contents.
2. Set repository visibility to Public.
3. Verify the root URL format is exactly `https://github.com/<github-username>/<repo-name>`.
4. Open the root README from an incognito browser window and verify that the commands work.
5. Upload the generated project report PDF to the VITyarthi project submission field.
6. Do not start an evaluation until the final version has been checked, because the portal states that evaluation-triggered submissions cannot be replaced.
