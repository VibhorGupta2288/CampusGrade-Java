# Project Statement

## Project Title
CampusGrade - Java Academic Performance Manager

## Problem Statement
Students and small academic project teams often keep marks in separate spreadsheets or notes, which makes it difficult to maintain student records, calculate weighted course performance, and obtain a quick course summary from one place.

CampusGrade addresses this problem with a command-line Java application that stores student and course information, records weighted assessments, calculates course percentages and GPA, and provides simple academic reports.

## Scope
The project covers:

- Student record management
- Course record management
- Weighted assessment entry
- Course percentage calculation
- Letter-grade and grade-point calculation
- Student GPA calculation
- Course class-average reporting
- What-if target percentage analysis
- File-based persistence using text files
- Input validation and error handling

The project does not include online authentication, a web interface, a relational database, or cloud deployment.

## Target Users

- Students who want a small local academic tracker
- Faculty or mentors demonstrating Java programming concepts
- Evaluators who need a simple, terminal-based project that can be executed without a GUI

## High-Level Features

1. Add and list students.
2. Add and list courses.
3. Record weighted assessments.
4. Generate a student performance report.
5. Generate a course summary.
6. Save and reload data from local files.
7. Validate incorrect inputs and reject duplicate IDs/codes.
